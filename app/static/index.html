Day-ahead demand forecasting · India

Can weather-aware machine learning improve day-ahead electricity-demand forecasts in India?

Solaris forecasts every hour of tomorrow's all-India electricity demand using only information a forecaster would genuinely have had the day before — including the archived weather forecast, never the observed weather.

How national demand moves with temperature, and whether weather information helps the forecast more when it is hot.

Association, not causation. These charts show that hot days and high demand occur together, and that temperature forecasts improve the model. They do not establish that temperature causes a given amount of demand. No causal identification strategy is used, and temperature is correlated with season, working patterns and economic activity.

    Reproduce it

    git clone https://github.com/dhairyabhosale/solaris
cd solaris
pip install -r requirements.txt

python -m solaris.cli fetch-grid      # ~713 MB from Mendeley
python -m solaris.cli fetch-weather   # archived forecasts, Open-Meteo
python -m solaris.cli prepare         # parse, join, quality-check
python -m solaris.cli train --rolling # fit and evaluate every model
python -m solaris.cli report          # regenerate figures and tables

uvicorn app.main:app --reload

    Every figure and table on this site is read from the files those commands write. Nothing here is hand-entered.
